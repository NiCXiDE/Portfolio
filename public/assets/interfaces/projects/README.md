# Nomenclatura de capturas UI

```
public/assets/interfaces/projects/{categoria}/{proyecto-slug}/{proyecto-slug}-0N.png
```

## Categorías
- `preventas`
- `sistemas-a-medida`
- `proyectos-personales`

## Ejemplos
- `sistemas-a-medida/aml-casinos/aml-casinos-01.png`
- `sistemas-a-medida/aml-general/aml-general-01.png`
- `preventas/adapto-pay/adapto-pay-01.png`

## Reglas
- 1–5 imágenes por proyecto (`-01` … `-05`)
- Sin nombres clave internos de cliente en el archivo (no “Inspector”, “Athenas”, etc.)
- Después de subir, listá las rutas en `content/interfaces/projects.json` → `images`
