# Manuales de marca

## Cómo sumar otro

1. `marca-x-cover.png` + `marca-x.pdf` en esta carpeta  
2. Entrada en `content/grafico/brand-manuals.json`

## Ejemplo (CITF)

```json
{
  "id": "citf",
  "cover": "/assets/grafico/brand-manuals/citf-manual-2025-cover.png",
  "pdf": "/assets/grafico/brand-manuals/citf-manual-2025.pdf",
  "title": { "es": "Manual de Marca 2025 CITF", "en": "Brand Manual 2025 CITF" },
  "year": "2025",
  "meta": {
    "es": "Clúster de Innovación Tecnológica Formosa",
    "en": "Formosa Technology Innovation Cluster"
  }
}
```

Click en la pieza → panel con detalle + **Descargar manual**.
